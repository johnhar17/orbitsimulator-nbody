# N-Body Gravitational Simulator

Sistem simulasi dinamika orbital N-Body menggunakan mesin integrator numerik Runge-Kutta Order-4 (RK4) untuk akurasi trajektori tinggi. Menggunakan PyQt5 dan PyQtGraph untuk real-time visualisasi di performa tinggi (~60FPS).

## Persyaratan
- Python 3.8+
- Sistem operasi Windows/macOS/Linux

## Instalasi dan Menjalankan Simulasi
1. Pastikan Anda berada dalam environment virtual python.
2. Install semua library yang tertera di dependencies:
   ```bash
   pip install -r requirements.txt
